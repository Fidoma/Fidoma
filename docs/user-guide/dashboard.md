# Dashboard

Das Dashboard fasst operative und finanzielle Werte für einen gewählten Zeitraum zusammen. Es zeigt KPIs, Umsatzentwicklung, Ein- und Auszahlungen sowie offene Aufgaben und Vorgänge.

## Typischer Ablauf

1. Zeitraum oder Quartal auswählen.
2. Umsatz und tatsächliche Zahlungseingänge getrennt betrachten.
3. Überfällige oder offene Vorgänge über die Aufgabenübersicht aufrufen.
4. Detaildaten in Rechnungen, Zahlungen oder Berichten prüfen.

::: info Fachliche Abgrenzung
Rechnungsumsatz entsteht durch Rechnungen; Cashflow basiert auf Zahlungen beziehungsweise Bankbewegungen. Die Werte sind deshalb nicht zwangsläufig identisch.
:::
