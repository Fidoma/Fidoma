# Zahlungen

Zahlungen gehören zu einer Rechnung und enthalten Zahlungsart, Datum, Betrag und Notiz. Sie können manuell erfasst, durch eine Rechnungszuordnung erzeugt oder nach einer erfolgreichen Terminalzahlung angelegt werden.

## Zahlungswege

- **Manuell:** Zahlung bei einer Rechnung beziehungsweise in der Zahlungsverwaltung erfassen.
- **Banktransaktion:** Positive, noch nicht verwendete Transaktion einer Rechnung oder bestehenden Zahlung zuordnen.
- **ZVT-Terminal:** Erfolgreicher Gateway-Vorgang erzeugt die Zahlung mit der konfigurierten Zahlungsart.

Teilzahlungen sind möglich. Die Rechnungsberechnung aktualisiert anschließend offenen Betrag und Status.

::: warning Zuordnung aufheben
Wird eine Zuordnung gelöst, unterscheidet Fidoma zwischen einer eigens durch die Zuordnung erzeugten Zahlung und einer zuvor vorhandenen Zahlung. Dadurch werden unabhängige Zahlungen nicht versehentlich gelöscht.
:::
